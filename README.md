## Description
Lists directories and files how I like.  Name short for перечислять or (perechislyat'); that is, to enumerate/list.

Disclaimer: this is an fairly simple script, which hardly compares to, for example, [exa](https://github.com/ogham/exa).  This programme is still in early phases of development, since being [ported from C](https://github.com/jakewilliami/scripts/blob/a00e53d/c/ls.c).

## Quick Start
```bash
$ ./compile.sh
$ ./pere -h
```
